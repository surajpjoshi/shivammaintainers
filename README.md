# SHIVAM Property Maintainers & Services website

A responsive, static website ready for GitHub Pages. It uses plain HTML, CSS and JavaScript—no build tools are required.

## Publish with GitHub Pages
1. Download and unzip `shivam-website-github-pages.zip`.
2. Open your GitHub repository (or create a new public repository named `shivam-website`).
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root. Keep the files together.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your published website URL in Settings → Pages.

## Customize
- Contact numbers, email and address are in `index.html`.
- Colours, layout and image links are in `style.css`.
- The current site uses online images from Unsplash and Google Fonts, so those visuals require an internet connection.
- The client list and company details were based on the supplied company profile. Please verify all details before publishing.
